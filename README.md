# Wedding invitation

A responsive, static South Indian inspired wedding invitation. Open index.html in a browser to preview it.

## Personalize it

Edit the wedding object at the top of script.js to change the names, date and time, venue, and map search. The RSVP form currently opens an email draft on the guest’s device; add a family email address in the mailto link or connect a form service when the RSVP destination is decided.

## Add your photos

Replace the decorative blocks in the hero and gallery with your images after they’re shared. The gallery has four slots; the large hero portrait has one. Local image files can live in an images folder.

The page uses Google Fonts when a network connection is available and falls back to system serif and sans-serif fonts.
